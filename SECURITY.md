# Security policy

This baseline has no independently audited production release. Use supported toolchains and patched runtime images.

Use GitHub private vulnerability reporting if enabled. Never publish credentials or exploit details in an issue. If private reporting is unavailable, request a private channel through an issue without disclosing the vulnerability. The maintainer must configure a private reporting channel before production rollout. No response SLA is promised yet.

See docs/THREAT_MODEL.md for guarantees and limits. Anonymity, traffic-analysis resistance and malicious-content detection are not guaranteed.
